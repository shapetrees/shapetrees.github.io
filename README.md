# shapetrees.github.io

The landing page for [Shape Trees](https://w3id.org/shapetrees), a
[W3C Solid Community Group](https://www.w3.org/community/solid/) work effort.

It is a static page with no build step. Because this repository is named
`shapetrees.github.io`, GitHub Pages serves it from `main` as the organization
site at <https://shapetrees.github.io/>. The site was formerly published at
`shapetrees.org`; that domain expired and is now squatted.

The two documents it links to live in their own repositories and have their own
Pages sites:

| Document | Repository | URL |
| --- | --- | --- |
| Specification | [shapetrees/specification](https://github.com/shapetrees/specification) | <https://shapetrees.github.io/specification/> |
| Primer | [shapetrees/primer](https://github.com/shapetrees/primer) | <https://shapetrees.github.io/primer/> |

The `w3id.org` redirect rules are kept in the specification repository, under
[`w3id/`](https://github.com/shapetrees/specification/tree/main/w3id).
